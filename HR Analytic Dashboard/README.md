# 📊 HR Analytics Dashboard – Power BI Project

## 📌 Project Overview

This HR Analytics Dashboard was created using Power BI to analyze employee data and generate meaningful business insights related to workforce management and employee attrition.

The dashboard helps organizations understand employee trends, job satisfaction, attrition patterns, and workforce distribution across different departments and education fields.

---

## 🎯 Objective

The main objective of this project is to:

* Analyze employee attrition trends
* Monitor workforce statistics
* Understand employee satisfaction levels
* Support HR decision-making using data visualization

---

## 🛠️ Tools & Technologies Used

* Microsoft Power BI
* Power Query (Data Cleaning & Transformation)
* DAX (Data Analysis Expressions)

---

## 📈 Dashboard Features

### 🔹 KPI Metrics

* Overall Employees
* Active Employees
* Attrition Count
* Attrition Rate
* Average Employee Age

### 🔹 Visual Analysis

* Department-wise Attrition
* Employee Distribution by Age Group
* Job Satisfaction Rating by Job Role
* Education Field-wise Attrition
* Attrition Analysis by Gender and Age Group

---

## 🔍 Key Insights

* Identified departments with higher employee attrition
* Compared employee satisfaction across job roles
* Analyzed employee distribution by age category
* Observed attrition patterns based on education field and gender
