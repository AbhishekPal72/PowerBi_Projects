# 📊 Sales Dashboard (Power BI)

## 📌 Project Overview

This project is a Sales Dashboard created using Power BI to analyze business performance from 2020 to 2022.

The dashboard provides insights into sales, profit, cost, and product performance.

---

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query (Data Cleaning)
* DAX (Data Analysis Expressions)

---

## 📈 Key Features

* KPI cards showing Total Sales, Profit, Cost, and Quantity
* Sales analysis by category
* Brand-wise performance visualization
* State-wise sales distribution (Map)
* Interactive dashboard with filters

---

## 🔍 Key Insights

* Highest sales come from top categories like Monitor and CPU
* Sales are concentrated in specific regions
* Profit trends show variation across brands
